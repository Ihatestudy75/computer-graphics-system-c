# Computer Graphics System in C

This repository contains a collection of computer graphics projects implemented in C. The work focuses on low-level graphics programming and visual computing concepts, including image processing, rasterization, transformations, viewing, and hierarchical scene construction.

## Topics Covered
- Image compositing and alpha blending
- Fractal and procedural texture generation
- Polygon rasterization and interpolation
- 2D and 3D transformations
- Viewing pipeline implementation
- Hierarchical module-based scene construction

## Tools
- C
- PPM image output
- Custom graphics/image structures

## Notes
This repository is based on coursework and project practice in computer graphics and is being refined as part of my technical portfolio.
